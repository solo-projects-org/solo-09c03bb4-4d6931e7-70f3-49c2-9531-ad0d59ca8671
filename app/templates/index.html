2. 生成重放起点检查点（旧提交转冷存储前留档）

填写目标版号，上传从 0 版到该版的 Delta Lake JSON 提交 （无需数据文件），生成按目标版号命名的经典单文件 Parquet 检查点，如 00000000000000000002.checkpoint.parquet。检查点保留该版生效的 protocol 与 metaData，每条路径只写生效的 add 或 remove（墓碑不按时间淘汰）， 文件动作 dataChange 写为 false，每个 appId 保留最后提交的 txn。 提交断档、日志无效或超出支持范围时会说明原因且不提供下载。
